# WeatherCast ☀️🌧️

A cross-platform weather forecast application built with Flutter, fully functional on both Android and iOS devices.

## About
**WeatherCast** is a lightweight and easy-to-use app that fetches and displays real-time weather forecasts.  
It supports manual city search and automatic GPS location detection, offering updated weather data with a smooth user experience.

## Features
- 🌍 **Dual Platform Support**: Works seamlessly on both Android and iOS devices.
- 🌤️ **Comprehensive Weather Data**: Displays current weather, min/max temperatures, sunrise and sunset times (powered by WeatherAPI).
- 📍 **Flexible Location Services**: Manual city search or automatic GPS location detection.
- 🔄 **Real-time Updates**: Pull-to-refresh functionality for instant data refresh.
- 📅 **Forecast Feature**: View weather predictions for upcoming days.
- 🛡️ **Error Handling**: State management using `setState` to manage and prevent user or data errors.
- 🎬 **Professional UX**: Professional splash screen and an interactive onboarding experience for first-time users.

## Technologies Used
- Flutter (Dart)
- WeatherAPI (for weather data)
- Location Services (GPS)
- State Management (setState)
- Git & GitHub for version control
